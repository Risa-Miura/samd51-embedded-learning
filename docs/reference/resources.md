# Learning resources

## Start here

- [Getting Started with Writing Code for the Microchip Arm Cortex Microcontrollers](https://mu.microchip.com/getting-started-with-writing-code-for-the-microchip-arm-cortex-microcontrollers) — primary starting course; summarize in original words.
- [Microchip SAM D5x/E5x training and application resources](https://onlinedocs.microchip.com/oxy/GUID-62CB236E-26C5-4CE9-A182-B1D33FE1512C-en-US-3/GUID-AB68F86C-5EE6-4358-B52F-2AB31E9D9EAD.html) — includes architecture, Harmony, peripheral library, and advanced application courses. Examples may use other boards.

## Device and board

- [ATSAMD51P20A product page](https://www.microchip.com/en-us/product/ATSAMD51P20A) — datasheet, current errata, and device documentation.
- [SAM D5x/E5x family datasheet](https://www.microchip.com/content/dam/mchp/documents/MCU32/ProductDocuments/DataSheets/SAM-D5x-E5x-Family-Data-Sheet-DS60001507.pdf) — register behavior and electrical/timing limits; record revision used.
- [Grand Central M4 guide](https://learn.adafruit.com/adafruit-grand-central) and [pinouts](https://learn.adafruit.com/adafruit-grand-central/pinouts) — board wiring and power/logic constraints.
- [Adafruit Arduino instructions](https://learn.adafruit.com/adafruit-grand-central/using-with-arduino-ide) — board package and upload workflow.
- [Adafruit SAMD Arduino core](https://github.com/adafruit/ArduinoCore-samd) — board definitions, startup code, and variants.
- [ARM CMSIS-Core documentation](https://arm-software.github.io/CMSIS_6/latest/Core/index.html) — core register and interrupt APIs.

## Notebook tooling

- [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) — writing, navigation, search, code, diagrams, and math.
- [GitHub Pages custom workflows](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) — official Pages artifact deployment.
- [Arduino CLI documentation](https://arduino.github.io/arduino-cli/latest/) — compile, upload, and board discovery.
- [JupyterLab](https://jupyterlab.readthedocs.io/en/stable/) — optional Python analysis environment.
