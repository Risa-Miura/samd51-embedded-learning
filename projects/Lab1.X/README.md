# SAME54 Microchip University Lab 1

This is the original imported ATSAME54P20A lab. Its C/header sources,
nbproject configuration, and Lab1.mplab.json have been preserved.

The independently configured ATSAMD51P20A blink project is now at
../01-led-blink/samd51-blink/. Open that folder in VS Code to build blink.
Do not add the Lab1 HEX image as a loadable to blink: both are complete
applications and their default flash layouts overlap.
